JovelL — Open source materials

JovelL uses the unmodified MobileVLCKit 3.7.0 dynamic framework from VideoLAN, build 591b8996-f9020c4d, under LGPL 2.1 or later.

The library sources include exact VLCKit and VLC revisions, upstream patches and build scripts, and 44 checksum-verified source archives selected by the iOS contrib configuration. All original notices remain in the archives. Some packages contain optional components with other licenses; the official LGPL build disables GPL and GNUv3 components.

The application relinking package includes arm64 Release objects, an unsigned resource bundle, the reference framework, a relinking script and instructions for signing with your own Apple developer identity. The application objects were successfully relinked locally. The entire upstream library toolchain was not rebuilt.

Permission is granted to use, modify and relink the supplied application objects for your own use with a modified library, and to reverse engineer the combined work for debugging such library modifications.
