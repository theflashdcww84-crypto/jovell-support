# JovelL support and privacy

Public support and privacy pages in English, Simplified Chinese, Japanese, Korean, Spanish and German. No analytics or third-party scripts.

This repository is a read-only publication snapshot for the support website. JovelL application development is maintained separately; application source and application build artifacts are not published here. The only release download is the corresponding third-party library source archive with its original notices.

Application relinking materials are provided inside the device release under Settings → Open source licenses → Export license materials.
