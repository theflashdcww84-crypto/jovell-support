Playback modes and loops

Tap the playback-mode control to choose In order, Repeat list, Repeat one or Shuffle. Repeat list restarts the current queue from its first item. Set A and B in the same panel to repeat a segment; B must be at least one second after A. Choosing another mode turns segment repeat off. Pause after the current file turns segment repeat off; enabling a valid A–B range cancels that end-of-file pause. A countdown timer can still pause segment repeat.

Import files by dragging

On iPad, drag local audio or video files from Files into the library, player or full-screen video view. Download cloud files first. Import copies the files and keeps the originals. The existing import limit and format rules still apply; failed or cancelled imports do not use a slot.
